# Contribution logs

This folder is where everyone tracks their own work on the project.

## What to do

1. Create your own file in this folder: `contribution_log_<YOUR NAME>.csv`.
2. Add one new row every time you make a change, with these columns:

| Column | What goes here |
|---|---|
| `date` | the date you did the work |
| `member_name` | your name |
| `hours` | how long it took you, roughly |
| `what_i_did` | a short description, see below |
| `functions_touched` | the name(s) of any function you wrote or changed, or `none yet` |
| `problems_met` | anything that went wrong, or `none` |

## Writing `what_i_did`

Keep it short and specific: what you did, then what you did it to.

✅ Good: `Added find_all_paths recursive function`

❌ Bad: `worked on stuff`

## A few rules

- Only add rows to your own file. Don't edit anyone else's.
- Never edit `contribution_log.csv` in the main project folder yourself.
  The `Documentation Lead` collects everyone's file and combines them into
  that one later.
